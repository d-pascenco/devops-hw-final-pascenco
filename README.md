# Итоговая работа - сервис audit-svc (Пащенко Дмитрий)

Сервис аудита: принимает события по HTTP и сохраняет их в PostgreSQL.
Подробные логи выполнения, шаги воспроизведения и графики - в [REPORT.md](REPORT.md) и ноутбуке [`final_Пащенко_Дмитрий.ipynb`](final_Пащенко_Дмитрий.ipynb).

## Структура репозитория

- `Dockerfile`, `.dockerignore` - многоступенчатая сборка сервиса (не от root, с воспроизводимыми слоями)
- `.gitlab-ci.yml` - пайплайн (тесты, сборка образов, деплой на защищённом теге)
- `deploy/` - развёртывание через Ansible:
  - `audit-svc.play.yml` - плейбук деплоя, запуск миграций и reload сервиса
  - `inventories/prom/` - инвентарь и зашифрованные секреты `vault.yml`
  - `templates/` - шаблоны конфига сервиса и nginx (с проксированием и закрытым `/reload`)
- `monitoring/` - стек мониторинга:
  - `compose.yaml` - запуск Prometheus и Grafana
  - `prometheus/prometheus.yml` - сбор метрик с сервиса (через nginx) и nginx-exporter
  - `grafana/` - дашборды сервиса (`audit-svc.json`) и nginx (`nginx.json`)
- `screenshots/` - скриншоты пайплайнов, окружения и мониторинга для отчёта

Пароль от vault лежит локально в `deploy/.vault_pass` (в `.gitignore`), в CI передаётся через защищённую переменную `ANSIBLE_VAULT_PASSWORD`.

## Заметки по реализации (на чём спотыкался)

- монтирование конфига: монтирую папку `/config`, а не сам `config.yaml`, потому что ансибловский модуль `template` пишет во временный файл и делает rename, из-за чего одиночный файл внутри докера оставался бы старым
- проксирование в nginx: адрес сервиса резолвится через встроенный DNS докера `127.0.0.11` с ttl 10s (переменная `$audit_svc`), иначе при пересоздании контейнера сервиса nginx кэшировал старый IP и выдавал 502
- воспроизводимость сборки: чтобы при смене тега из того же коммита не пересоздавался контейнер сервиса, в Dockerfile зафиксировал `SOURCE_DATE_EPOCH=0` и `--no-compile`, а в kaniko добавил `--reproducible` (иначе менялся digest образа и докер рестартовал сервис вместо reload)
- права на конфиг 0640: сервис работает под пользователем `audit` (uid 1001), поэтому в контейнер пробросил группу раннера (`groups`), чтобы не давать небезопасные права 777
